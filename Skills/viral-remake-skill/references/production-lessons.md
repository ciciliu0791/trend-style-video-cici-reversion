## WorkBuddy wig remake: retain the V2 gain

Evidence: [project retrospective and user feedback](../../../videos/workbuddy-wig-remake/RETROSPECTIVE-ANALYSIS-2026-10-25.md), [V1 approved prompt](../../../videos/workbuddy-wig-remake/package-v1.1.json) and [V2 prompt](../../../videos/workbuddy-wig-remake/VIDEO-PROMPT-v2.txt). These support the following lessons, not a newly performed full playback/listening review.

| Finding | Apply in future work | Limit |
|---|---|---|
| V1 explicitly requested `sitting calmly` and `two very small head turns` despite the chosen exaggerated grooming mechanism | Compare the exact prompt with the selected acting function before submission; preserve agency, not just wig/mirror/dryer props | Calm behavior may be correct for a different source; no keyword ban |
| V2 restored lifted-chin poses, larger hair sweeps, formal clothing, mirror staging and a deadpan finish | Keep action stages and visual contrast explicit; give identity, scene, expression and motion references distinct duties | The user said "v2生成的效果好了很多"; simultaneous changes do not isolate the effect of model choice |
| Source evidence included intermediate styling/completion states, while generated conditions emphasized opening/ending | Cover the actual unresolved action, not a fixed image count; video reference may suffice | Evidence frames and generation inputs need not correspond one-to-one |
| The ending face crop retained part of the collar/tag region and the output showed duplicate tags | Inspect exact cropped pixels and conflicting references, not just the role description | Correlation is not proof of the unique defect cause |
| The local preview left media materialization unresolved | Put useful input checks before paid generation and record evidence level | Neither successful fetching nor omitted reference video was proven |
| User experience improved while continuous playback/listening checks remained incomplete | Record the positive feedback alongside open checks; synchronize current cut/task/editor versions | Praise is not new spending, publication authority or an unperformed QA pass |

Use this chain in existing records: `source evidence -> mechanism -> adapted behavior/view -> actual prompt clause -> reference authority -> output check`. Do not create six new documents or compulsory new approval stages. For a cast unable to perform the original gesture, choose a concrete equivalent or surface the tradeoff; do not automatically replace the performance with passive motion.
